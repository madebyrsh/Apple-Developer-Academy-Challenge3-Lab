## 📌 저장소 목적

> Challenge3 팀 프로젝트에서 사용된 기능을 직접 재구현하며 학습하기 위한 개인 저장소

Apple Developer Academy @ POSTECH Challenge3 과정에서 
개발 중인 팀 프로젝트의 기능들을 직접 다시 구현하며 학습하기 위한 저장소입니다.

이 저장소의 목적은 단순히 코드를 읽는 것이 아니라,

- 기능 분석
- 핵심 개념 이해
- 기능 재구현
- 구현 검증

과정을 통해 기능을 완전히 자신의 것으로 만드는 것입니다.

## 📌 Repository Purpose

> A personal repository for rebuilding and learning features 
used in the Challenge3 team project.

This repository was created to rebuild and understand features
developed in the Challenge3 team project during the Apple Developer Academy @ POSTECH.

The goal is not simply to read code, but to:

- Analyze features
- Understand core concepts
- Rebuild implementations
- Validate functionality

and ultimately make each feature your own through hands-on implementation.
